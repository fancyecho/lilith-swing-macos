# v1.3.2 · 稳定置顶与坐姿承托

## 本次更新

- 修复站在秋千上切换窗口时容易被弹飞的问题：使用兼容置顶策略，移除周期性重新置前。
- 修复秋千位于较高位置时，莉莉丝落座后很快掉落的问题：新增独立透明承托，覆盖坐姿下移后的检测位置。
- 可见座板、皮肤比例与拖动范围保持不变，扩展承托完全穿透鼠标，不阻挡下方窗口操作。
- 穆夏皮肤改为更明亮的浅蜜色木材与单一鸢尾花章，减少小尺寸下的繁杂细节；顶部改为完整冠饰素材。
- 更新安装时完整替换应用并保留旧版备份，避免旧资源残留破坏签名。
- 补充窗口、几何与鼠标穿透配置测试，并更新实际皮肤预览。

## 验证

已通过基础回归、30 次真实窗口顺序检查、应用签名与压缩包校验。本机游戏实测确认：高处可持续落座，点击其他窗口不乱飞，座板下方仍可正常点击。

## 下载与安装

- `Lilith-Swing-macOS-arm64-v1.3.2.zip`：Apple Silicon 应用；解压后打开 `莉莉丝秋千.app`。
- `Lilith-Swing-source-v1.3.2.zip`：完整源码、安装脚本与说明；需要登录自动启动时，在解压目录运行 `zsh install.zsh`。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

最低编译目标为 macOS 11，实际游戏验收环境为 macOS 27。兼容置顶使用可选私有系统接口，不受 Apple 稳定性保证；其他系统尚未逐一验证。应用为本地 ad-hoc 签名，未做 Apple 公证。

菜单“兼容置顶（实验性）”可以关闭置顶及透明承托，恢复普通短座板用于对比排查。不修改游戏文件，不需要关闭系统保护。
