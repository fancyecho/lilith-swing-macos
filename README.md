# 莉莉丝秋千

一个给 macOS Steam 桌宠游戏《不存在的莉莉丝》使用的轻量悬浮秋千。

![macOS](https://img.shields.io/badge/macOS-11%2B-6f7b50)
![Apple Silicon](https://img.shields.io/badge/Apple%20Silicon-arm64-bb8b47)

## 特点

- 木质座板提供一条平直窗口上沿，让莉莉丝能够坐上去。
- 两条藤蔓会根据座板高度自动延伸到屏幕顶部，不再使用固定长度。
- 拖动座板时隐藏藤蔓，松开后藤蔓从顶部向下生长，减少画面突变。
- 独立皮肤引擎，将窗口行为与座板、藤蔓、顶部冠饰的渲染完全分离。
- 首套“穆夏 · 鸢尾”皮肤使用浅蜜色木材、旧金、象牙与鼠尾草绿；大面积安静色块围绕单一鸢尾花章展开，缩小后仍保持清晰层级。
- 顶部冠饰使用一张为 28 pt 浅窗口专门构图的完整素材，左右花章、鞭状曲线与中央鸢尾不会再被屏幕边缘裁断。
- 装饰窗口保持窄或矮，避免被莉莉丝识别为额外落脚面。
- 菜单栏常驻，可选择皮肤、显示、隐藏、居中或退出；安装后支持登录自动启动。
- 实验性“兼容置顶”：保持普通窗口身份供游戏识别，同时固定在普通窗口前、莉莉丝后；不再每 0.8 秒反复抢回窗口顺序。
- 独立透明承托从座板延伸到屏幕底部，覆盖坐姿下移后的检测位置；外观与拖动区域不扩大，新增区域完全穿透鼠标。

## 使用

可直接获取[最新应用与源码下载包](https://github.com/fancyecho/lilith-swing-macos/releases/latest)。当前版本为 **v1.3.2**，更新内容见[版本说明](Docs/releases/v1.3.2.md)。

1. 运行 `./install.zsh`。
2. 直接拖动木质座板到想要的位置。
3. 双击座板可回到屏幕中央；右键座板或点击菜单栏的 `❧` 可打开菜单。

安装脚本会把应用放入 `~/Applications`，并创建当前用户的登录启动项。卸载时运行 `./uninstall.zsh`，相关文件会移到废纸篓。

更新时会完整替换应用，旧版本保留在 `~/Library/Application Support/LilithSwing/Backups`；位置与皮肤设置不会被重置。菜单栏“兼容置顶（实验性）”可以随时关闭，便于对比排查。

关闭兼容置顶时也会隐藏扩展承托，恢复原来的普通短座板；正常使用建议保持开启。

## 手动构建

```sh
./build.zsh
```

构建结果位于 `build/莉莉丝秋千.app`。项目仅依赖 macOS 自带的 AppKit 和命令行开发工具。

发布包为 Apple Silicon（arm64）。构建最低目标系统从 `Info.plist` 读取，目前为 macOS 11；实际游戏验收仅在 macOS 27 完成，不代表已验证所有旧系统。应用采用本地 ad-hoc 签名，未做 Apple 公证。

生成皮肤的明暗背景预览：

```sh
./preview.zsh
```

## 皮肤结构

```text
SkinEngine/          皮肤协议、素材清单加载与注册表
WindowEngine/        兼容置顶策略与透明承托几何
Skins/
  Mucha/
    skin.json        名称、窗口指标、素材与裁切区域
    MuchaSkin.m      三类组件的排版与渲染
    Assets/          座板、顶部冠饰、可重复藤蔓素材
Tools/               独立皮肤预览渲染器
```

座板、藤蔓和顶部冠饰是三个明确的渲染组件。窗口管理、拖动和生长动画位于主程序，皮肤只决定指标与画面；新增皮肤不需要复制交互代码。详细约定见 [皮肤引擎说明](Docs/skin-engine.md)。

## 实现说明

莉莉丝会读取系统窗口边界来生成可站立或可坐的表面。兼容模式把可见座板与游戏承托分开：座板仍以原尺寸绘制和接收拖动，承托保持相同顶边与宽度、向下延伸到屏幕底部，并完全忽略鼠标事件。承托是唯一满足游戏条件的座位窗口，可见座板使用游戏不扫描的显示层级；藤蔓与花饰至少有一个维度保持在最小窗口阈值以下。

当前版本以主屏幕为活动范围。

“兼容置顶”使用可选的 macOS 私有子层级接口，仅操作秋千自身窗口，不修改游戏、不注入其他进程，也不需要关闭系统保护。接口不受 Apple 兼容性保证；系统不支持时会回退为普通窗口并在菜单中提示。它不承诺覆盖全屏应用、系统界面或其他置顶窗口。原理、限制与验证步骤见 [窗口兼容说明](Docs/window-compatibility.md)。

窗口行为测试：

```sh
zsh test.zsh
# 在已登录的 macOS 桌面额外验证真实窗口顺序：
zsh test.zsh --window-server
```
